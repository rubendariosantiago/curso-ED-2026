1. Introducción y Objetivos

¡Bienvenidos a esta sesión de Ecuaciones Diferenciales! Hoy abordaremos una familia especial de ecuaciones no lineales que, gracias a un ingenioso cambio de variable, pueden transformarse en ecuaciones lineales de primer orden. Hablamos de la Ecuación Diferencial de Bernoulli.

Una ecuación de Bernoulli tiene la forma estándar:

$$ \frac{dy}{dx} + P(x)y = Q(x)y^n $$

Donde \(n\) es cualquier número real. Si \(n = 0\) o \(n = 1\), la ecuación ya es lineal y sabemos cómo resolverla (usando un factor integrante). Sin embargo, cuando \(n \neq 0\) y \(n \neq 1\), la ecuación es no lineal. El método de resolución consiste en realizar la siguiente sustitución universal para este caso:

$$ u = y^{1-n} $$

Al derivar esta expresión respecto a \(x\) mediante la regla de la cadena (\( \frac{du}{dx} = (1-n)y^{-n}\frac{dy}{dx} \)), y manipular la ecuación original, esta se reduce mágicamente a una ecuación diferencial lineal de primer orden en términos de \(u(x)\). ¡Comencemos nuestra exploración!

2. Desarrollo y Ejercicios Operativos

A continuación, resolveremos 5 ejercicios de nivel intermedio y avanzado. Observa cuidadosamente cómo se identifica \(n\), cómo se construye el factor integrante y cómo se revierte el cambio de variable al final.

Ejercicio 1 (Nivel Intermedio)

Resuelve la ecuación diferencial: \( y' + \frac{1}{x}y = xy^2 \)

Solución:

1. Identificamos que es una ecuación de Bernoulli con \(P(x) = \frac{1}{x}\), \(Q(x) = x\) y \(n = 2\).

2. Aplicamos la sustitución \( u = y^{1-n} = y^{1-2} = y^{-1} \). Derivando: \( u' = -y^{-2}y' \).

3. Para que aparezca este término, multiplicamos toda la ecuación original por \(-y^{-2}\):

$$ -y^{-2}y' - \frac{1}{x}y^{-1} = -x $$

4. Sustituimos \(u\) y \(u'\):

$$ u' - \frac{1}{x}u = -x $$

5. Esta es una ecuación lineal estándar. Buscamos el factor integrante \( \mu(x) \):

$$ \mu(x) = e^{\int -\frac{1}{x} dx} = e^{-\ln(x)} = x^{-1} = \frac{1}{x} $$

6. Multiplicamos la ecuación lineal por \( \frac{1}{x} \):

$$ \frac{1}{x}u' - \frac{1}{x^2}u = -1 \implies \frac{d}{dx}\left( u \cdot \frac{1}{x} \right) = -1 $$

7. Integramos ambos lados:

$$ u \cdot \frac{1}{x} = -x + C \implies u = -x^2 + Cx $$

8. Finalmente, regresamos a la variable original \( y = u^{-1} = \frac{1}{u} \):

$$ y(x) = \frac{1}{Cx - x^2} $$

Ejercicio 2 (Con Graficación en Python)

Resuelve el problema de valor inicial: \( y' - y = e^x y^2 \) con \(y(0) = 1\).

Solución:

1. Ecuación de Bernoulli con \(n = 2\). Sustitución: \(u = y^{-1}\), con \(u' = -y^{-2}y'\).

2. Multiplicamos por \(-y^{-2}\):

$$ -y^{-2}y' + y^{-1} = -e^x \implies u' + u = -e^x $$

3. Factor integrante: \( \mu(x) = e^{\int 1 dx} = e^x \).

4. Multiplicando la lineal por \(e^x\):

$$ e^x u' + e^x u = -e^{2x} \implies \frac{d}{dx}(u e^x) = -e^{2x} $$

5. Integrando:

$$ u e^x = -\frac{1}{2}e^{2x} + C \implies u(x) = -\frac{1}{2}e^x + C e^{-x} $$

6. Regresando a \(y\):

$$ y(x) = \frac{1}{Ce^{-x} - \frac{1}{2}e^x} $$

7. Aplicamos la condición inicial \(y(0) = 1\):

$$ 1 = \frac{1}{C(1) - \frac{1}{2}(1)} \implies C - 0.5 = 1 \implies C = 1.5 = \frac{3}{2} $$

Por lo tanto, la solución particular es:

$$ y(x) = \frac{2}{3e^{-x} - e^x} $$

Código en Python (Matplotlib + NumPy):

import numpy as np
import matplotlib.pyplot as plt

# Definir el dominio (evitando la asíntota donde 3e^{-x} = e^x => x = ln(sqrt(3)) ≈ 0.549)
x = np.linspace(-1, 0.5, 400)
# Solución particular
y = 2 / (3 * np.exp(-x) - np.exp(x))

plt.figure(figsize=(8, 5))
plt.plot(x, y, color='blue', linewidth=2, label=r'$y(x) = \frac{2}{3e^{-x} - e^x}$')
plt.axhline(0, color='black', linewidth=1)
plt.axvline(0, color='black', linewidth=1)
plt.scatter([0], [1], color='red', zorder=5, label='Condición Inicial y(0)=1')
plt.title('Solución a la Ecuación de Bernoulli')
plt.xlabel('x')
plt.ylabel('y(x)')
plt.grid(True, linestyle='--', alpha=0.7)
plt.legend()
plt.show()

Ejercicio 3 (Nivel Avanzado)

Resuelve la ecuación: \( x^2 y' + 2xy = y^3 \)

Solución:

1. Primero, llevamos a la forma estándar dividiendo entre \(x^2\):

$$ y' + \frac{2}{x}y = \frac{1}{x^2}y^3 $$

2. Identificamos \(n = 3\). Sustituimos \(u = y^{1-3} = y^{-2}\). Derivada: \(u' = -2y^{-3}y'\).

3. Multiplicamos la ecuación por \(-2y^{-3}\):

$$ -2y^{-3}y' - \frac{4}{x}y^{-2} = -\frac{2}{x^2} \implies u' - \frac{4}{x}u = -\frac{2}{x^2} $$

4. Factor integrante: \( \mu(x) = e^{\int -\frac{4}{x} dx} = e^{-4\ln(x)} = x^{-4} \).

5. Multiplicamos por \(x^{-4}\):

$$ x^{-4}u' - 4x^{-5}u = -2x^{-6} \implies \frac{d}{dx}(u x^{-4}) = -2x^{-6} $$

6. Integramos:

$$ u x^{-4} = \frac{-2}{-5}x^{-5} + C = \frac{2}{5}x^{-5} + C \implies u(x) = \frac{2}{5}x^{-1} + C x^4 $$

7. Volviendo a \(y\), recordamos que \(u = \frac{1}{y^2} \implies y^2 = \frac{1}{u}\):

$$ y^2 = \frac{1}{\frac{2}{5x} + Cx^4} = \frac{5x}{2 + 5Cx^5} \implies y = \pm \sqrt{\frac{5x}{2 + 5Cx^5}} $$

Ejercicio 4 (Con Graficación en Python)

Resuelve \( y' + y = x y^3 \) con \( y(0) = 1 \).

Solución:

1. Es de Bernoulli con \(n = 3\). Cambio \(u = y^{-2}\), por tanto \(u' = -2y^{-3}y'\).

2. Multiplicando por \(-2y^{-3}\):

$$ -2y^{-3}y' - 2y^{-2} = -2x \implies u' - 2u = -2x $$

3. Factor integrante: \( \mu(x) = e^{-2x} \).

4. Reescritura: \( \frac{d}{dx}(u e^{-2x}) = -2x e^{-2x} \).

5. Integramos el lado derecho por partes (tomando \(w=x, dv=-2e^{-2x}dx\)):

$$ \int -2x e^{-2x} dx = x e^{-2x} - \int e^{-2x} dx = x e^{-2x} + \frac{1}{2}e^{-2x} + C $$

6. Sustituyendo:

$$ u e^{-2x} = e^{-2x}\left(x + \frac{1}{2}\right) + C \implies u(x) = x + \frac{1}{2} + C e^{2x} $$

7. Condición inicial: \(y(0)=1 \implies u(0)=1^{-2}=1\).

$$ 1 = 0 + \frac{1}{2} + C e^{0} \implies C = \frac{1}{2} $$

8. Solución final (\(y = 1/\sqrt{u}\)):

$$ y(x) = \frac{1}{\sqrt{x + \frac{1}{2} + \frac{1}{2}e^{2x}}} = \sqrt{\frac{2}{2x + 1 + e^{2x}}} $$

Código en Python:

import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(0, 3, 500)
# Solución analítica evaluada
y = np.sqrt(2 / (2*x + 1 + np.exp(2*x)))

plt.figure(figsize=(8, 5))
plt.plot(x, y, color='green', linewidth=2.5, label='Curva de decaimiento')
plt.fill_between(x, y, alpha=0.1, color='green')
plt.title('Solución: Decaimiento No Lineal')
plt.xlabel('x')
plt.ylabel('y(x)')
plt.grid(True)
plt.legend()
plt.show()

Ejercicio 5 (Nivel Avanzado - Funciones Trigonométricas)

Resuelve \( y' + y \cot(x) = y^4 \csc(x) \)

Solución:

1. Aquí \(n = 4\). \(u = y^{-3} \implies u' = -3y^{-4}y'\).

2. Multiplicando la ED por \(-3y^{-4}\):

$$ -3y^{-4}y' - 3\cot(x)y^{-3} = -3\csc(x) \implies u' - 3\cot(x)u = -3\csc(x) $$

3. Factor integrante (\(\int -3\cot(x)dx = -3\ln|\sin(x)|\)):

$$ \mu(x) = e^{-3\ln(\sin x)} = \sin^{-3}(x) = \csc^3(x) $$

4. Multiplicamos la ecuación lineal:

$$ \csc^3(x)u' - 3\csc^3(x)\cot(x)u = -3\csc^4(x) \implies \frac{d}{dx}(u \csc^3(x)) = -3\csc^4(x) $$

5. Para integrar \(-3\csc^4(x)\), separamos \(\csc^2(x)\csc^2(x)\) y usamos \(\csc^2(x) = 1 + \cot^2(x)\):

$$ \int -3(1+\cot^2(x))\csc^2(x) dx $$

Haciendo \(w = \cot(x), dw = -\csc^2(x)dx\):

$$ 3 \int (1+w^2) dw = 3\left(w + \frac{w^3}{3}\right) = 3\cot(x) + \cot^3(x) + C $$

6. Despejando \(u\):

$$ u \csc^3(x) = 3\cot(x) + \cot^3(x) + C \implies u(x) = 3\sin^2(x)\cos(x) + \cos^3(x) + C\sin^3(x) $$

7. La solución para \(y\) es:

$$ y(x) = \frac{1}{\sqrt[3]{3\sin^2(x)\cos(x) + \cos^3(x) + C\sin^3(x)}} $$

3. Aplicaciones Prácticas

Como aplicación principal, trabajaremos con Modelos de Dinámica de Poblaciones y Propagación Epidémica. Muchos sistemas dinámicos donde el crecimiento está limitado por los recursos (o la población total) se rigen por variaciones de la ecuación logística, la cual es intrínsecamente una Ecuación de Bernoulli.

Ejemplo Aplicado 1: El Modelo Logístico de Crecimiento

La ecuación logística describe una población \(P(t)\) que crece en un entorno con capacidad de carga \(K\):

$$ \frac{dP}{dt} = rP \left( 1 - \frac{P}{K} \right) = rP - \frac{r}{K}P^2 $$

Planteamiento: Demuestra que esta es una ED de Bernoulli y encuentra la solución general.

Solución:

Reescribimos la ecuación: \( P' - rP = -\frac{r}{K}P^2 \). Es Bernoulli con \(n = 2\).

Sustituimos \(u = P^{-1} \implies u' = -P^{-2}P'\).

Multiplicando por \(-P^{-2}\): \( u' + ru = \frac{r}{K} \).

Factor integrante: \(\mu(t) = e^{rt}\). Obtenemos: \( \frac{d}{dt}(u e^{rt}) = \frac{r}{K}e^{rt} \).

Integrando: \( u e^{rt} = \frac{1}{K}e^{rt} + C \implies u(t) = \frac{1}{K} + C e^{-rt} \).

Como \(P = 1/u\), la solución es: $$ P(t) = \frac{1}{\frac{1}{K} + C e^{-rt}} = \frac{K}{1 + (KC)e^{-rt}} $$

Ejemplo Aplicado 2: Modelo Epidémico SIS

En una enfermedad donde los individuos infectados \(I(t)\) se recuperan sin inmunidad, la tasa de cambio de infectados en una población constante \(N\) es: \( I' = \beta I (N - I) - \gamma I \).

Planteamiento: Resuelve para \(I(t)\).

Solución:

Reagrupando: \( I' - (\beta N - \gamma)I = -\beta I^2 \). Es Bernoulli con \(n = 2\).

Haciendo \(\alpha = \beta N - \gamma\), tenemos \( I' - \alpha I = -\beta I^2 \). El cambio \(u = I^{-1}\) produce:

$$ u' + \alpha u = \beta $$

Resolviendo la lineal con \(\mu = e^{\alpha t}\): \( u e^{\alpha t} = \frac{\beta}{\alpha}e^{\alpha t} + C \implies u(t) = \frac{\beta}{\alpha} + C e^{-\alpha t} \).

Solución: $$ I(t) = \frac{1}{\frac{\beta}{\beta N - \gamma} + C e^{-(\beta N - \gamma)t}} $$

4. Exploración Interactiva (Formativa)

Actividad Formativa: Copia el siguiente código en un entorno de Google Colab para explorar cómo los campos de direcciones de una ecuación de Bernoulli reaccionan ante cambios de parámetros. (Esta actividad no es calificable). 
import numpy as np
import matplotlib.pyplot as plt
from scipy.integrate import odeint

# Modelo Logístico (Bernoulli n=2): dP/dt = r*P - (r/K)*P^2
def modelo(P, t, r, K):
    return r * P - (r/K) * P**2

t = np.linspace(0, 10, 100)
# Parámetros ajustables
r = 1.2
K = 50

# Graficar varias condiciones iniciales
plt.figure(figsize=(10,6))
for P0 in [5, 10, 25, 75, 100]:
    sol = odeint(modelo, P0, t, args=(r, K))
    plt.plot(t, sol, label=f'P(0) = {P0}')

plt.axhline(K, color='r', linestyle='--', label='Capacidad de Carga K')
plt.title('Dinámica del Modelo de Bernoulli (Logístico)')
plt.xlabel('Tiempo')
plt.ylabel('Población')
plt.legend()
plt.grid()
plt.show()
